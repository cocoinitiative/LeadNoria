## 10. BUILD-SCRIPT IMMUTABILITY AUDIT

[scripts/build-extension.mjs](file:///e:/project%20anti/leadnoria/scripts/build-extension.mjs) was audited for release safety and error handling:

### Strengths:
1. **Accidental Overwrite Protection:** Lines 367-372 guard `dist/leadnoria-v1.7.5.zip` with `if (!fs.existsSync(releaseZipPath16))`. If the file exists, archiving is skipped and a preservation message is logged.
2. **Mirror Synchronization:** Lines 374-380 copy `dist/leadnoria-v1.7.5.zip` to `extension.zip` via `fs.copyFileSync`, guaranteeing that both files maintain identical contents and timestamps.
3. **Copy Failure Propagation:** If `fs.copyFileSync` fails (e.g. read-only filesystem or permissions error), Node.js throws an unhandled exception and exits with a non-zero exit code.

### Weaknesses & Operational Risks (Finding AUDIT-01):
1. **No Source-to-Archive Drift Detection:** The existence check only detects whether a file with that name exists. If source files in `src/extension/` are modified and `node scripts/build-extension.mjs` is run:
   - `esbuild` will recompile the modified files into `./extension/`.
   - The script will skip updating `dist/leadnoria-v1.7.5.zip`.
   - The script will copy the *old* `dist/leadnoria-v1.7.5.zip` to `extension.zip`.
   - The script will exit with code `0`.
   - As a result, `./extension` would contain new code while `dist/leadnoria-v1.7.5.zip` contains old code, silently creating an inconsistency without warning.
2. **Current Repository State:** In the current working tree, **no drift exists**. The uncompressed contents of `dist/leadnoria-v1.7.5.zip` match `./extension/` byte-for-byte.
